# Lab 3 — Variant 1 (JS)
**Patterns:** Composite + Strategy

## Task
Build a simple project task manager:
- **Composite**: tasks can be grouped into projects (tree structure: projects → tasks/subprojects).
- **Strategy**: each task can be executed using a chosen methodology/algorithm (Agile, Waterfall, Spiral, RUP).

## How to run
```bash
npm install
npm start
```

## Output
The demo in `src/index.js` builds a project with subtasks and executes it.
