# Figures JS

Учебное приложение на JavaScript (Node.js) по ТЗ:

- Геометрические фигуры (Circle, Triangle, Point)
- Репозиторий (Repository pattern) для хранения фигур
- Спецификации поиска (Specification pattern)
- Сортировки с компараторами
- Warehouse (Singleton + Observer) с площадями / периметрами / объёмами
- Тесты на Jest

## Запуск

```bash
npm install
npm test
npm start
```

Код в папке `src`, тесты в `__tests__`.
